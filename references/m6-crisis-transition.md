# M6 위기·전환 관리 — 규모별 패턴

## 핵심 프레임워크
- **Greiner 위기 모델:** 각 성장 단계 끝에 위기 발생. 해법이 다음 위기의 씨앗.
- **Kotter 8단계 변화관리:** 조직 내부 변화 실행 경로.
- **경영 실패 패턴 5대:** ①리더십-운영 단절 ②인센티브 불일치 ③인프라 미비 ④문화 희석 ⑤성장통 무시
- **핵심 원리:** 위기는 예측 가능. Greiner 모델의 다음 위기를 미리 준비하면 "혁명"이 "진화"가 됨.

---

## 규모별 패턴

### S1 (1-5명)
- **주요 위기:** 공동창업자 갈등, 자금 고갈, 제품 실패.
- **성공 패턴:** 갈등 시 "이거 안 되면 어떻게 할지" 사전 합의(창업자 계약). 빠른 피봇.
- **실패 패턴:** 갈등 회피 → 잠복 → 폭발. 또는 피봇 타이밍 놓침.
- **Greiner:** Phase 1 → 리더십 위기. "누가 이끌 것인가?"

### S2 (6-15명)
- **주요 위기:** 첫 핵심인재 이탈, 창업자 번아웃, 방향 전환 필요.
- **성공 패턴:** 핵심인재 이탈 시 빠른 복구 + 근본 원인 분석. 창업자 역할 재정의.
- **실패 패턴:** 핵심인재 이탈을 "배신"으로 인식 → 근본 원인 미분석 → 반복.
- **Greiner:** Phase 1→2 전환. 창업자가 "만드는 사람"에서 "이끄는 사람"으로 전환 거부.

### S3 (16-50명)
- **주요 위기:** 성장통(실패패턴 #5). 창업자 위임 실패. 초기 문화 vs 새 문화 충돌.
- **성공 패턴:** 위임 단계적 실행 + 중간관리자 코칭 + 문화 전환 명시적 관리.
- **실패 패턴:** "내가 더 잘 하는데" → 모든 결정 병목. 또는 급격한 구조 변화 → 기존 멤버 반발.
- **Kotter 적용:** Step 1(위기감) — "지금 방식으로는 100명에서 작동 안 한다" 공유.

### S4 (51-150명)
- **주요 위기:** 던바 벽 접근. 커뮤니케이션 붕괴. 문화 희석. 핵심인재 대량 이탈.
- **성공 패턴:** 사전 구조화(S3에서 준비) + 위기 감지 시스템(이직률, 참여도 서베이) + Kotter 8단계 적용.
- **실패 패턴:** "우리는 다르다"(성장통 무시). 150명인데 5명 때 방식 고수.
- **Greiner:** Phase 3 → 통제 위기. 위임했더니 방향이 갈라짐.

### S5 (151-500명)
- **주요 위기:** 사업부 간 사일로. 관료화 시작. 혁신 속도 저하. 경영진 교체.
- **성공 패턴:** 사일로 파괴 메커니즘(cross-functional 프로젝트) + 관료화 감지·제거 + 경영진 승계 계획.
- **실패 패턴:** 관료화 방치 → A급 인재 이탈 가속 → 혁신 사망. 또는 구조조정 실패 → 사기 붕괴.
- **Greiner:** Phase 4 → 관료화(Red Tape) 위기.

### S6 (500+명)
- **주요 위기:** 시장 전환 대응 실패. 인수 후 통합(PMI) 실패. 내부 정치.
- **성공 패턴:** 전략적 위기 관리 체계(위기 대응팀, 시나리오 플래닝) + PMI 전담 + 혁신 조직 분리.
- **실패 패턴:** 성공의 저주("기존 방식이 최고") → 시장 전환 놓침. 또는 인수 기업 문화 충돌 → 인재 이탈.
- **Greiner:** Phase 5 → 내부 성장 한계. 외부 솔루션(M&A, 파트너십) 필요.

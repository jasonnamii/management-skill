# 보고서 템플릿

## 3블록 서사 구조

모든 모드(진단/설계/처방)의 최종 출력은 이 구조를 따른다.

### Layer 1: 판단 1문장
```
"[규모 단계] 조직의 핵심 병목은 [축명]이며, [규모 전환 상태]에 있다."
```
예: "S4(80명) 조직의 핵심 병목은 M3(실행시스템)이며, S3→S4 전환이 미완료 상태다."

### Layer 2: 서사 (모드별)

**진단 모드:**
상황 구조화 → 규모 매칭 → 6축 건강도 → 병목 축 심화 → 실패 패턴 경고 → 권장 액션

**설계 모드:**
목표 규모 확인 → 현재-목표 갭 → 축별 전환 로드맵 → 전환 매트릭스 적용 (이 규모에서의 정답 + 이전 규모에서 왜 틀린지) → 우선순위

**처방 모드:**
위기 상황 구조화 → 실패 패턴 5대 중 매칭 → 규모 맥락 적용 → 조건부 대응 전략 (유효 조건 + 무효 조건) → 우선순위 → 시간축

### Layer 3: 데이터 부록
- 스크리닝 테이블 (6축 ●/○/- 판정)
- 로드된 spoke 목록
- 성공/실패 대조쌍 상세
- 규모별 전환 매트릭스 해당 셀

---

## 서사 규칙

| 규칙 | 이유 |
|---|---|
| 축 사전식 나열 금지 | 나열은 판단을 돕지 못함. 상황→패턴→인과→처방 서사로 |
| 블록당 3문장 이상 | 1줄 판정만으로는 맥락 부족 |
| 대조쌍 = 같은 규모 | S3 성공 vs S3 실패. 규모 다른 비교는 무의미 |
| 분석 순서 ≠ 출력 순서 | 내부: 스크리닝→로드→분석. 출력: Layer 1→2→3 |
| biz-skill 위임 명시 | "이 판단은 전략 영역 — biz-skill [축코드] 참조 권장" |

## 6축 건강도 판정 기준 (진단 모드)

| 등급 | 의미 | 판정 기준 |
|---|---|---|
| 🟢 건강 | 현 규모에 적합한 운영 패턴 작동 중 | spoke 패턴과 일치 |
| 🟡 주의 | 현 규모에 부분 적합하나 다음 규모 전환 준비 부족 | 부분 일치 + 전환 미비 |
| 🔴 위험 | 이전 규모 패턴으로 운영 중이거나 패턴 부재 | 불일치 또는 부재 |

## 예시 — 진단 모드 출력

**Layer 1:**
S4(80명) 조직의 핵심 병목은 M3(실행시스템)이며, S3→S4 전환이 미완료 상태다.

**Layer 2:**
80명 규모에서 주간회의와 OKR이 있으나, 의사결정 프로토콜(RACI)이 부재하여 모든 결정이 창업자에게 집중되고 있다. 이것은 전형적인 S3 패턴(창업자 직접관여)이 S4(공식 프로토콜 필요) 규모에서 그대로 유지되는 "성장통 무시(실패패턴 #5)" 상황이다.

S4에서 M3 실행시스템이 작동하는 조직은 RACI 기반 의사결정 위임 + 분기 OKR + 주간/월간/분기 3단 케이던스를 갖추고 있다. 반면 동일 규모에서 M3가 실패한 조직은 "모든 것이 창업자 승인 대기"로 속도가 0에 수렴하며, 핵심 인재가 자율성 부족으로 이탈한다(실패패턴 #1 리더십-운영 단절 + #2 인센티브 불일치).

**Layer 3:** (스크리닝 테이블, spoke 로드 목록, 대조쌍 상세 등)

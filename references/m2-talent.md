# M2 인재 파이프라인 — 규모별 패턴

## 핵심 프레임워크
- **인재관리 5단계:** 채용(Acquire) → 온보딩(Onboard) → 성장(Develop) → 리텐션(Retain) → 이탈(Transition)
- **Collins Level 5:** 겸손+결단의 리더. "First Who, Then What" — 먼저 맞는 사람을 버스에 태워라.
- **A급 인재 밀도:** Netflix 원칙. 인재 밀도가 떨어지면 프로세스가 늘어나고, 프로세스가 늘면 A급이 떠남.

---

## 규모별 패턴

### S1 (1-5명)
- **채용:** 공동창업자 = 최중요 인재 결정. 기술+문화+비전 완전 정렬 필요.
- **성공 패턴:** 다재다능한 제너럴리스트. 역할 경계 없이 문제 해결.
- **실패 패턴:** 우정 기반 공동창업 → 역할·책임·지분 미합의. 창업 후 갈등 폭발.
- **리텐션:** 해당 없음 (떠나면 회사 자체가 위기).

### S2 (6-15명)
- **채용:** 첫 전문가 영입. 창업자가 못 하는 영역(예: 영업, 디자인) 보완.
- **성공 패턴:** 문화 적합성 + 전문성 교차 채용. 온보딩 = 창업자가 직접 1:1.
- **실패 패턴:** 전문성만 보고 문화 불일치 채용 → 초기 문화 파괴. "스타 플레이어인데 팀을 망가뜨림."
- **리텐션:** 미션·비전·equity가 주 동력. 급여 경쟁력보다 성장 기회.

### S3 (16-50명)
- **채용:** 채용 프로세스 구조화 시작. Job description, 면접 기준, 채용 파이프라인.
- **성공 패턴:** 구조화된 면접 + 문화 면접 분리 + 채용 기준 문서화. 온보딩 프로그램 시작.
- **실패 패턴:** 급성장 압박에 "일단 뽑자" → 인재 밀도 급락 → A급 이탈 시작.
- **리텐션:** 성과관리 도입 필요. 성장 경로(career path) 최초 설계.

### S4 (51-150명)
- **채용:** 전담 HR/리크루터 필요. Employer branding 시작.
- **성공 패턴:** 체계적 파이프라인 + 데이터 기반 채용 + 온보딩 90일 프로그램 + 성과 리뷰 주기화.
- **실패 패턴:** 문화 희석(실패패턴 #4). 대량 채용이 기존 문화를 압도. 또는 핵심인재 이탈 시작 — "예전 같지 않다."
- **리텐션:** 보상 패키지 체계화 (equity+cash+성장 mix). 1:1 미팅 정례화. 이탈 분석 시작.

### S5 (151-500명)
- **채용:** 인재 시스템 구축. ATS, 성과관리 플랫폼, 리더십 개발 프로그램.
- **성공 패턴:** 리더십 파이프라인 — 내부 승진 + 외부 영입 밸런스. 후계자 계획(Succession Planning).
- **실패 패턴:** 관리자 부족 — 개인 기여자를 무조건 관리자로 승진 → 관리 역량 없는 관리자 양산.
- **리텐션:** 사업부별 문화 차이 인정 + 전사 공통 가치 유지. 퇴사 면담 체계화.

### S6 (500+명)
- **채용:** 글로벌 인재 전략. 다양성·포용성 체계화. 대규모 채용 품질 관리.
- **성공 패턴:** 인재 데이터 분석 + 예측적 리텐션 + 리더십 아카데미 + 내부 이동 시스템.
- **실패 패턴:** 대기업병 — 관료적 채용 → 혁신 인재 기피. "큰 회사에서 일하고 싶은 사람"만 모임.

# M4 문화 엔지니어링 — 규모별 패턴

## 핵심 프레임워크
- **Schein 3층:** ①인공물(사무실, 복장, 의식) → ②표방가치(미션, 원칙) → ③기저가정(무의식적 신념)
- **Kotter 8단계 변화관리:** 위기감→연합→비전→동원→장벽제거→단기성과→가속→정착
- **Lencioni 5역기능:** 신뢰부재→갈등회피→헌신부족→책임회피→결과무관심
- **Dalio 급진적 투명성:** 아이디어 성과주의 = 급진적 진실 + 급진적 투명성 + 신뢰도 가중 의사결정
- **핵심 원리:** 문화는 "결과물"이 아니라 "설계 대상". 방치하면 무작위 문화가 형성됨.

## 규모별 패턴

### S1 (1-5명)
- **문화 전파:** 창업자 = 문화. 별도 전파 불필요. 행동이 곧 문화.
- **성공 패턴:** 창업자가 원하는 문화를 행동으로 보여줌. "말보다 행동."
- **실패 패턴:** 공동창업자 간 가치관 불일치가 잠복 → 규모 커지면 폭발.
- **Schein 관점:** 기저가정(③)이 창업자 행동에서 직접 형성. 의식적 설계 불필요.

### S2 (6-15명)
- **문화 전파:** 창업자가 직접 전파. 면접에서 문화 적합성 판단. "우리 같은 사람인가?"
- **성공 패턴:** 핵심 가치 3-5개 명문화 시작. 채용 시 문화 기준 적용.
- **실패 패턴:** 문화 = 복지(간식, 게임) 착각. 기저가정 무시.
- **Lencioni 관점:** 5역기능 중 "신뢰 부재"가 이 규모에서 가장 큰 리스크.

### S3 (16-50명)
- **문화 전파:** 암묵지→명시지 전환 필수. 핵심 가치 문서화 + 온보딩에 통합.
- **성공 패턴:** 가치 기반 의사결정 사례 공유. "우리는 이런 상황에서 이렇게 한다" 스토리.
- **실패 패턴:** 문서만 있고 실천 안 함("벽에 걸린 가치"). 또는 암묵지 상태 유지 → 새 멤버가 문화 학습 불가.
- **Schein 관점:** 인공물(①)과 표방가치(②)를 의식적으로 설계해야 기저가정(③) 전파 가능.

### S4 (51-150명)
- **문화 전파:** 중간관리자 = 문화 캐리어. 관리자가 문화를 체화해야 팀에 전파.
- **성공 패턴:** 관리자 대상 문화 교육 + 문화 기반 성과 평가 + 갈등 해결 프로토콜.
- **실패 패턴:** 문화 희석(실패패턴 #4). 50→150 급성장에서 "다른 문화의 사람"이 다수가 됨.
- **Kotter 관점:** 이 규모에서 문화 변화 시도 시 8단계 전체 필요. 특히 "주도 연합"(중간관리자)이 핵심.

### S5 (151-500명)
- **문화 전파:** 제도화 필수. 문화 = 시스템으로 작동. 개인 의존 불가.
- **성공 패턴:** 문화 위원회 또는 전담 역할 + 정기 문화 서베이 + 하위문화 허용(사업부별 개성) + 전사 공통 가치.
- **실패 패턴:** 문화 경찰화("이게 우리 문화야!") → 자율성 질식. 또는 하위문화 방치 → 전사 정체성 소멸.
- **Dalio 관점:** 급진적 투명성 같은 강력한 문화는 이 규모에서 "시스템으로 강제"해야 유지.

### S6 (500+명)
- **문화 전파:** 플랫폼화. 문화 인프라(교육·의식·상징·인센티브) 체계.
- **성공 패턴:** 강한 공통 가치 + 사업부별 적응 + 문화 측정·개선 루프.
- **실패 패턴:** 대기업 문화 경직 → 혁신 사망. 또는 인수 후 문화 충돌 방치.
